# thunderbird-tray

The tray program of [Thunderbird Tray](https://github.com/kemalasliyuksek/thunderbird-tray). It works
together with the Thunderbird Tray add-on, which it talks to through native messaging, and does
nothing on its own.

```bash
uv tool install thunderbird-tray   # or: pipx install thunderbird-tray
thunderbird-tray install           # tell Thunderbird where the tray program is
thunderbird-tray status            # check the setup
```

See the [project README](https://github.com/kemalasliyuksek/thunderbird-tray#readme) for the add-on,
the features and troubleshooting.
